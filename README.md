# Crime Management System

## Overview
The Crime Management System is a database-driven web application designed to improve communication between citizens and law enforcement agencies. The system provides a centralized platform where citizens can view crime-related information and updates, while police authorities can manage and maintain crime records efficiently.


## Features
1.Citizen Portal
- View recent crime reports and updates.
- Access crime statistics and information.
- Stay informed about incidents in different areas.
- User-friendly interface for easy navigation.

2.Police Portal
- Add new crime records.
- Update existing crime information.
- Manage and maintain crime databases.
- Track and monitor reported incidents.

## Objectives
- Provide citizens with timely crime-related information.
- Improve crime record management for law enforcement agencies.
- Maintain accurate and organized crime data.
- Enhance transparency and communication between citizens and police.


## Project Workflow
1. Police officers enter crime details into the system.
2. Crime information is stored securely in the database.
3. Citizens can view updated crime information through the portal.
4. Police can modify, update, and manage records whenever required.
